# HEW Diamonds — Frontend Demo

A mobile-first, static website demo built with HTML, CSS and JavaScript.

## Run locally
Open `index.html` in a browser, or use VS Code Live Server.

## Deploy to GitHub Pages
1. Create a GitHub repository.
2. Upload all files and folders in this project to the repository root.
3. In Settings → Pages, choose Deploy from a branch, select `main` and `/ (root)`.
4. Save and wait for the Pages URL.

## Demo behaviours
- Homepage scroll scenes in the agreed order.
- Category listing and product detail views.
- Product gallery thumbnails.
- Add to cart, quantity changes, wishlist and browser localStorage.
- Demo checkout confirmation (no payment).
- Account and orders placeholder screens.
- Search drawer and mobile navigation.

## Before presenting
- Replace the sample jewellery images in `assets/` with HEW-approved product photography.
- Update product names, specifications, prices, gold rate, contact details and WhatsApp number in `app.js` / `index.html`.
- The price formula and rates are illustrative demo values only. They are not connected to a live gold-rate source.
- CCAvenue is represented as a visual placeholder only. No payment is processed.
- Google Reviews link points to the HEW link supplied in the conversation.
